# OpenMagFDM v1.7.1

2026-10-23 — 2D解析・WebUI・サーバー運用の改善リリース。

macOSソルバーの配布はApple Silicon / arm64向けの`OpenMagFDM-macOS-arm64.tar.gz`です。WebUI単体のmacOS配布はIntel / x64向けで、ソルバーとは別の実行ファイルです。

## 改善内容

- ファイル数上限をCLIで変更できるようになりました。共通の既定値とユーザー領域ごとの設定に対応し、既存ファイルを保持します。`help` / `--help` / `-h`で全管理コマンドを確認できます。
- ドキュメントを`docs/`に集約し、過去のリリースノート・開発計画を移動して索引を追加しました。

- WebUIとMCPの解析を共通の永続ジョブへ統合しました。リロードや通信断後に進捗・ログ・取消操作を復元できます。受付の重複を防ぎ、受付時点の入力を保存します。
- 元画像・YAML・参照入力・ハッシュを保存し、保存失敗時は解析を開始しません。入力フォルダーの経過日数による自動削除を廃止しました。
- descriptionの常設編集、極座標XYの縦横比固定、入力画像なしのAz磁力線表示を追加しました。一括削除は操作IDで追跡でき、部分失敗や再接続を扱います。
- Plotly更新を直列化し、次ステップの準備中も現在のグラフを保持します。Preloadのキャッシュ量・停止理由・計測情報を表示します。
- 保存先設定・検証付きコピー移行、アカウント・作業領域割当をCLIへ追加しました。既定は従来どおりloopback HTTP、明示的な共有モードではHTTPSとログインを要求します。
- ブラウザーライブラリーをローカル配信し、LAN内のオフライン利用に対応します。
- 配布EXEのNode.jsを24.22.1に固定し、公式Nodeを利用するSEA方式へ変更しました。Jimp・Multerの既知の脆弱性を修正し、画像前処理の形式・領域・サイズ検査と一時ファイル回収を強化しました。詳細は[2026-10-23の診断記録](../archive/reviews/NODE_SECURITY_REVIEW_20261023.md)を参照してください。

2Dの計算方式と既存YAMLの意味は変更していません。GPU試作、STEPボクセル化ツール、独立3Dソルバー基盤はこの配布対象に含めません。

## 更新・移行

1. 実行中の解析を完了または取消し、サーバーを停止します。
2. 結果・設定・画像・材料ライブラリーと、管理情報をバックアップします。Windowsの管理情報は `%LOCALAPPDATA%/OpenMagFDM/automation/` 配下です。結果ZIPだけには管理情報が含まれません。
3. 同じ配置先でアプリケーションを更新し、既存データフォルダーを保持します。配置先を変える場合は管理情報の基準パスも変わるため、旧管理情報を保持したうえで移設を検証します。
4. ローカル起動で既存結果・設定・ジョブを確認します。再起動前の実行ジョブは`interrupted`、待機ジョブは`held`になります。保留分はResume操作で再開します。
5. 共有利用を有効にする場合だけ、管理者作成、既存領域の割当、HTTPS設定を行います。未割当領域は一般利用者へ公開しません。

保存先変更は自動移動を伴いません。移行はサーバー停止中の`storage migrate-results`でコピー・ハッシュ検証・設定切替を行い、移行元を残します。
具体的なコマンドとセッションの扱いは[運用手順](../archive/operations/V1_7_1_OPERATIONS.md)を参照してください。

## API・MCPの変更

解析受付・照会・取消は`/api/jobs`を使用します。接続寿命に依存した`/api/solve`、`/api/solve-stream`、`/api/stop-solver`と広範な静的公開`/data`はHTTP 410になります。外部クライアントには移行が必要です。旧結果自体の一括変換は不要です。

MCP接続は引き続きローカル限定です。共有HTTPSからのHelp / Integrationsによるペアリング管理は未対応です。必要な接続はローカルモードで設定してから共有へ切り替え、作業領域の所有者割当と有効状態を確認してください。接続設定を変更する場合もサーバー停止後にローカルモードへ戻して管理します。

## 検証状況と公開前の残作業

WindowsでNode回帰100件、C++回帰5件、入力保存・HTTPS・実ソルバー・保存先移行の統合試験、配布ステージング試験を実施しています。実行結果は開発記録と照合してください。

2026-10-23にNode24.22.1でNode回帰100件を再確認し、Windows配布EXEのHTTP/stdio MCP・画像API・実ソルバー、Chrome/Edgeのheadless実ブラウザー操作も確認しました。Node依存のauditは0件です。各試験の範囲とWindowsの長い保存先で検出した別課題は診断記録に記載しています。

ファイル上限とCLI helpを含むNode回帰102件、C++回帰5件が成功しています。各OSの数値回帰・配布ビルド、Node/MCP検証、Windowsインストーラーの構築はタグのCIで確認して公開します。手動の全操作・30分の描画耐久試験は今回の検証範囲に含みません。Windowsでは非常に長い保存先パスでソルバー出力が失敗することがあるため、短い保存先を使用してください。共有HTTPSからのMCPペアリング管理の制約は上記手順を参照してください。
