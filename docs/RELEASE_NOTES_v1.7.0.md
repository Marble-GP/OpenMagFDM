# OpenMagFDM v1.7.0

## 主な変更

- WebUIの作業導線・ファイル管理・結果表示を整理。表示中のデータを明示し、未読込時は読込操作へ案内。
- YAML入力支援、検査、未保存編集の保護と材料ライブラリ要約を改善。
- Node 24内蔵サーバーにMCPを統合。HTTPとstdioブリッジから、割当ユーザーの設定・材料・画像・解析・結果を操作可能。
- MCPは初回OFF。権限、入力スナップショット、更新リビジョン、冪等起動、監査ログを提供。
- 管理ブラウザーを任意で30日間信頼でき、GUIから解除可能。MCP接続設定とON/OFFは再起動後も復元。
- ソルバーは配布フォルダー内を自動検出。GUIで保存した絶対パスも利用でき、SOLVER_PATHは上書き用に維持。
- ソルバーの残差評価・接線・作業領域・初期解に関する研究コード、回帰試験、比較記録を収録。
  研究用のopt-in設定を一律に新しい既定値へ変更するリリースではない。

## セットアップ

[READMEのMCP手順](../README.md#mcp-setup)と[詳細仕様](MCP_INTEGRATION.md)を参照。
初回はHelp & Integrationsでサーバーの確認コードを入力し、必要な権限だけを持つ接続を作成する。
普段はサーバーの起動だけで既存の接続を再利用できる。stdioブリッジはサーバーを自動起動しない。
保存したソルバー設定の変更は次回起動から適用される。

## 確認済みと既知の制約

- Windows: 軽量回帰90件、配布exeのHTTP/stdio実解析、正常収束・未収束警告・CSV取得を確認。
- SOLVER_PATHなしで、サーバーexeに隣接するソルバーを検出して解析できることを確認。
- OpenCode: 小モデルの入力参照、起動・冪等再送、結果・警告取得の受入試験を確認。
- Linux/macOSを含むビルド・数値回帰とMCP配布物接続検証はリリースActionsで実施し、
  必須ジョブが成功するまで自動公開しない。
- 長時間連続使用の保持量、実解析中の切断/OFFとGUI操作の組合せ、全ブラウザーの表示確認は継続課題。
- results_tableはCSVのみ。TIFFの数値行列デコードは未提供。yaml_inspectは物理的妥当性を保証しない。
- files_listで結果内部を参照するときは、categoryを省略してprefixに完全なワークスペースIDを渡す。
- ソルバー準備失敗の診断説明、テンプレート共通化、依存画像処理ライブラリの更新は継続課題。
- MCPのユーザー境界はOSサンドボックスやWebUI全体の多人数認証基盤ではない。
  共有PCではブラウザーを信頼せず、削除・置換権限は必要な接続にのみ与える。

[OpenCode用の小モデル試験手順・ZIP生成方法](MCP_ACCEPTANCE_TEST.md)も利用できる。
